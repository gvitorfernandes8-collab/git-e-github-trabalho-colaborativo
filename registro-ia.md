# Registro de uso da inteligência artificial

**Projeto:** Cartilha digital — primeiros passos com Git e GitHub.  
**Grupo:** Vitor Gomes Fernandes, Gustavo Kenji Noguchi, Bianca Souza Ferreira, Matheus Augusto Batista da Silva e Nathan André Silva.  
**Ferramenta:** ChatGPT (OpenAI).  
**Data de preparação:** 6 de novembro de 2026.

## 1. Para que a IA foi utilizada?

A IA foi utilizada como apoio para estruturar a cartilha, simplificar explicações para iniciantes, organizar o roteiro prático, propor exemplos de mensagens de commit e indicar tópicos para conferência na documentação oficial.

## 2. Prompts utilizados

**Prompt 1 — pesquisa e organização**

> Somos iniciantes em Git e GitHub. Explique, em linguagem simples, a diferença entre Git e GitHub, repositório público e privado, README, Markdown, commit, histórico, branch, pull request e merge. Organize os assuntos como uma cartilha para ser lida diretamente no GitHub e indique o que deve ser confirmado na documentação oficial.

**Prompt 2 — roteiro prático**

> Crie um roteiro para três estudantes realizarem, somente pelo navegador e sem terminal, a criação de um repositório, convite de colaboradores, edição sequencial de um arquivo, commits individuais, consulta do histórico e uma alteração por branch, pull request, revisão e merge. Não afirme que os testes foram feitos; deixe campos para registrar os resultados reais.

**Prompt 3 — revisão didática**

> Revise o tutorial para uma pessoa iniciante. Verifique se os conceitos estão diferenciados, se cada etapa tem sequência clara e se há alertas sobre exposição de informações em repositórios públicos. Aponte o que deve ser testado na plataforma antes da entrega.

## 3. Como as respostas foram conferidas

As orientações foram comparadas com páginas oficiais do GitHub Docs sobre criação e visibilidade de repositórios, README, Markdown, edição de arquivos, convites, pull requests e merge. Os links consultados estão listados em `cartilha.md`.

A conferência documental não substitui o teste prático. O grupo ainda precisa confirmar o aceite dos convites, realizar commits individuais, criar e revisar o pull request, concluir o merge e inserir capturas reais.

## 4. Ajustes e limites

- O material foi preparado para uso pelo navegador; não exige terminal.
- Os nomes de usuário de Gustavo e Bianca não foram presumidos.
- O perfil da professora indicado no enunciado deve ser confirmado antes de considerar o convite concluído.
- Não foram inventados resultados de testes, autores de commits, links de pull request ou capturas de tela.
- A interface pode mudar. Em caso de diferença, prevalecem a documentação oficial atual e o resultado do teste real.
